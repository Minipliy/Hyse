# USDA FNDDS 2021–2023 catalogue

The normalized seed `fndds_2021_2023_foods.json.gz` is derived from the USDA
FoodData Central Food and Nutrient Database for Dietary Studies (FNDDS)
2021–2023 JSON release dated 2024-10-31.

Source: https://fdc.nal.usda.gov/download-datasets/

USDA FoodData Central data are in the public domain. Nutrient values and the
original English food descriptions are retained. German display names were
created locally with the open-source Argos Translate English–German model and
are explicitly marked as translations in each record's provenance note.
